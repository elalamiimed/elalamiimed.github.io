Research & Engineering Projects

LearnyBrain — adaptive tutoring agent

private

Agent harness that probes where a learner's understanding ends, maps the dependency path to a goal, then teaches and verifies one reasoning step at a time; a persistent knowledge graph carries state across sessions. An exercise in agent state, step-wise verification and long-horizon coherence.

TypeScript · Next.js · Electron

Amnesia — local-first memory for LLM agents

public

Long-term memory layer for Ollama models: hybrid SQLite full-text and embedding recall behind an MCP interface, no cloud and no telemetry. The research question is the audit surface — what an agent stores, when it retrieves it, and how contradictory memories change behaviour.

Python · SQLite · MIT · ~11.5k lines · 16 test files

Agentica — guarded bilingual writing pipeline

public

A 27-question intake produces a publication-ready EN/中文 draft, which is then gated by a deterministic rejection checklist distilled from 17 approved articles and 130 headings. An exercise in constraining generation with explicit, testable criteria.

Python · LLM APIs · 13 QA test files

CryptoBot — empirical study of 41,470 token launches

public

Labelled launch corpus (41,470 launches, 45,000+ on-chain tapes) used to test whether early observables predict extreme outcomes. A gradient-boosted classifier improved from ROC-AUC 0.60 to 0.75 across launch windows; 18 written reports. Paper trading only — no wallet, no signing.

Python · pandas · scikit-learn · XGBoost

MISO — 20-engine gold macro research system

private

Twenty signal engines (COT positioning, intermarket, volatility, ETF flows, COMEX, USD liquidity) aggregate into weekly and daily decisions, with an 18-tab dashboard and reproducible backtests. Every signal is traceable to its input and every decision reproducible from stored state.

Python · FastAPI · SQLite · Streamlit · 82k lines · 486 files · 37 test files

Pump Terminal — fail-closed trading terminal

local only

Production-oriented Solana terminal with realtime candles and tape, volume profile, deterministic paper replay and a three-gate risk engine. The live gate fails closed: if a precondition cannot be verified, the system does nothing — the closest engineering analogue to enforcing hard constraints.

FastAPI · Next.js · Postgres/TimescaleDB · Redis · 116k lines · 552 Python tests

Session-Sweep Engine — strategy as an evaluable specification

public

Event-driven Backtrader backtester for an XAUUSD session-liquidity-sweep strategy; every rule from the playbook became an explicit, testable precondition (seven gates, 2% risk model, daily circuit breaker) on real gold data.
